Phase 1b: Dataset Curation

Crucial Note on Kaggle Dataset Quality

The original SWaT Kaggle dataset contains severe structural corruption. The timeline is fragmented with over 70 massive time jumps (some skipping 16 hours forward, and one violent jump of 11 days backwards). Because standard ML models panic at physically impossible time-jumps, setting up this pipeline required extreme mathematical resilience. Our models implement "Gap-Aware" windowing to seamlessly bridge these corruptions.

Cleans the datasets by perfectly aligning columns, stripping whitespaces, resolving duplicated entries, and gracefully interpolating (forward-filling) time-series sensor dropouts.

            What this means: The algorithm mathematically translates infinite continuous floating-point sensor readings (like FIT101) into a finite, discrete alphabet of symbols (like FIT101_BIN: 3). This allows strict logic algorithms like Process Mining and Automata Learning to read physical behavior as a sequence of discrete events.
